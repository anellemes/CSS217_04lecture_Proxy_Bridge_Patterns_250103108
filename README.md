
# README — Proxy & Bridge Patterns Lab (Java)

## Anelya Satybaldiyeva & Overview

Complete solutions for the **Proxy & Bridge Patterns in Java** lab worksheet — two fundamental Structural Design Patterns from the Gang of Four (GoF) catalog.

| Pattern | Category | Purpose |
|---------|----------|---------|
| **Proxy** | Structural | Controls and mediates access to a real object through a surrogate |
| **Bridge** | Structural | Decouples an abstraction from its implementation so both can vary independently |

Both patterns solve the same core problem — avoiding class explosion — but from different angles: Proxy defers/controls access, Bridge separates two dimensions of variation.
